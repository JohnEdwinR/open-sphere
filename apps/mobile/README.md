# Open Sphere — Mobile (Not Yet Scaffolded)

React Native + Expo client. Per the [Roadmap](../../01_PRODUCT/Roadmap.md), this app is built in **Phase 4 (Mobile App)**, after the Backend & Persistence phase gives it a real API/WebSocket contract to talk to.

Scaffolding this now (before Phase 3 ships `05_API/APISpecification.md`'s endpoints for real) would mean building against a contract that doesn't exist yet — so this directory is intentionally a placeholder until that phase starts.

See [Architecture §6](../../03_SOFTWARE_ARCHITECTURE/Architecture.md#6-client-architecture-mobile) for the intended client architecture (Zustand, React Query, MMKV, React Native Skia, Reanimated, Socket.IO client).
